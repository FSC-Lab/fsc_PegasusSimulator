1101 Valve Turning Review

Four static-hold attempts, none reached the hold, the last one crashed. The crash and the three recent ones share one sequencing choice the box push never made: the claw was held in the room before the grasp, and the base error grew while it was. The operator then closed the jaws by hand (the static-hold test had automatic Push off) with the base about 100 mm off: the room-held claw looked settled. The valve's phase logic now mirrors the 10-27 box push; two abort and exit timings were aligned today. The in-contact sway of a free handle is a separate, unsolved problem.

Three sequencing decisions made the crash, none of them a gain: the room hold before the grasp (during which the base error grew to 110 mm and the arm reached q1 −23°), the gain/contact switch read off the gripper joint instead of a planner event, and an abort recipe that starts from a still reference while the base moves at ~350 mm/s. The claw, following the base, swept the opening jaws across the fin for 2 s and caught it in the climb. The sway guard did what it was built for; the abort it started has no answer for a base that is already moving fast.

2.2 What still differs, and why

  • Exit anchor order. The box releases to the CoM anchor before the jaws open; the valve opens with the claw room-held and stays room-held for the first 6 cm of the climb. Chosen on Isaac evidence for a free handle (10-18: 3/3 vs 2/7; 10-28: 3/3 vs 2/6). Never flown on hardware either way for the valve. The 1 s extra wait was removed today.
  • Gains. Both Ky 120 / Dy 20.2, Kψ 0.25, kR/kω 1.6/1.2. Box: the push axis at natural inertia (My 1.64, Ky,y 196.8) and ωc,t 1.0; valve ωc,t 2.0 (10-17: 1.0 let the base wander 40–64 mm in the turn). The valve adds the heading companion (the EE heading target turns with the free-axis offset, radius 0.16 m) and the arm release at a SAFETY handover.
  • Geometry. Approach height 0.10 vs 0.15 m, exit climb 0.20 vs 0.25 m, the push pose [0, 5, 25, 0] vs [0, 28, 32, 0] (the skids over the beam).
  • Static hold. Valve only: the station reports the grasp and the release to the planner as events; the box has no equivalent because its Push press is the event.

2.3 What the 11-01 build did instead (for the record)

Room hold from the end of Go To Start; leash 40 mm releasing and re-engaging the hold; Ready CoM gate 30 mm / 60 mm/s; descent room-held with a 60 mm guard; gripper joint read by the node to switch gains and the heading companion; jaws opened at Go To Start; abort at the planned hold, 2 s, world-held release key; exit +1 s after OPEN. None of these exist in the box push, and none survive in the isolation branch.
